───────────────────────────────────────────────────────────────────────────────
[FN-002] FUNCIÓN: processCesar(mode)
───────────────────────────────────────────────────────────────────────────────
 
UBICACIÓN EN EL CÓDIGO: Líneas 333-387
 
PROPÓSITO:
Procesa el texto ingresado aplicando el algoritmo de cifrado César con
desplazamiento configurable. Incluye detección automática de desplazamiento
cuando el modo es 'decrypt'.
 
PARÁMETROS:
- mode (string): 'encrypt' para cifrar o 'decrypt' para descifrar.
 
FUNCIONAMIENTO:
1. Captura de datos desde los campos de entrada
   - Texto a procesar.
   - Valor de desplazamiento.
   - Conjunto de caracteres.
   
2. Validación de datos
   - Verifica que el texto no esté vacío.
   - Verifica que el conjunto de caracteres esté definido.
 
3. Detección automática (NUEVO)
   - Si mode='decrypt': Llama a autoDetectShift() para detectar el desplazamiento.
   - Actualiza el valor del campo de desplazamiento si la detección es exitosa.
   - Guarda información sobre el desplazamiento detectado.
   
4. Determinación de dirección
   - Si mode='encrypt': desplazamiento positivo.
   - Si mode='decrypt': desplazamiento negativo (detectado o manual).
   
5. Procesamiento carácter por carácter
   - Busca posición del carácter en el conjunto.
   - Aplica desplazamiento con operación módulo.
   - Maneja desbordamiento circular.
   - Caracteres fuera del conjunto se mantienen iguales.
   
6. Visualización del resultado
   - Si fue detección automática: muestra cuadro informativo con desplazamiento detectado.
   - Si fue manual: muestra solo el resultado.
 
ALGORITMO MATEMÁTICO:
Para cifrar:   nueva_posicion = (posicion + desplazamiento) mod longitud
Para descifrar: nueva_posicion = (posicion - desplazamiento) mod longitud
 
PSEUDOCÓDIGO:
INICIO processCesar(mode)
    // [FN-002.1] Captura de datos
    texto = obtener valor de cesarInput
    desplazamiento = obtener valor de cesarShift
    conjunto = obtener valor de cesarCharset
    
    // [FN-002.2] Validaciones
    SI texto está vacío ENTONCES
        mostrar alerta "ingresa un texto"
        RETORNAR
    FIN SI
    
    SI conjunto está vacío ENTONCES
        mostrar alerta "define un conjunto"
        RETORNAR
    FIN SI
    
    // [FN-002.2b] Detección automática (NUEVO)
    auto_detectado = falso
    desplazamiento_detectado = desplazamiento
    coincidencias = 0
    
    SI mode == 'decrypt' ENTONCES
        resultado_deteccion = autoDetectShift(texto, conjunto)
        SI resultado_deteccion.encontrado ENTONCES
            desplazamiento = resultado_deteccion.desplazamiento
            desplazamiento_detectado = desplazamiento
            coincidencias = resultado_deteccion.coincidencias
            auto_detectado = verdadero
            actualizar campo cesarShift con desplazamiento detectado
        FIN SI
    FIN SI
    
    // [FN-002.3] Inicialización
    resultado = ""
    longitud_conjunto = longitud de conjunto
    
    SI mode == 'encrypt' ENTONCES
        desplazamiento_real = desplazamiento
    SINO
        desplazamiento_real = -desplazamiento
    FIN SI
    
    // [FN-002.4] Procesamiento
    PARA cada caracter en texto HACER
        posicion = buscar caracter en conjunto
        
        SI posicion encontrada ENTONCES
            nueva_posicion = (posicion + desplazamiento_real) mod longitud_conjunto
            
            SI nueva_posicion < 0 ENTONCES
                nueva_posicion = nueva_posicion + longitud_conjunto
            FIN SI
            
            resultado = resultado + conjunto[nueva_posicion]
        SINO
            resultado = resultado + caracter
        FIN SI
    FIN PARA
    
    // [FN-002.5] Mostrar resultado
    SI auto_detectado ENTONCES
        mostrar cuadro informativo con desplazamiento y coincidencias
        mostrar resultado
    SINO
        mostrar solo resultado
    FIN SI
    hacer visible cesarResult
FIN
 
EJEMPLO DE USO:
Input: "HOLA", desplazamiento: 3, conjunto: "ABCD...XYZ"
processCesar('encrypt')
Output: "KROD"
 
Input cifrado: "KROD", conjunto: "ABCD...XYZ"
processCesar('decrypt')
Output: "HOLA" (con detección automática de desplazamiento 3)

[FN-004] FUNCIÓN: autoDetectShift(input, charset) - NUEVA FUNCIÓN
───────────────────────────────────────────────────────────────────────────────
 
UBICACIÓN EN EL CÓDIGO: Líneas 390-441
 
PROPÓSITO:
Detecta automáticamente el desplazamiento correcto de un texto cifrado con
César mediante análisis de frecuencia de palabras comunes en español.
 
PARÁMETROS:
- input (string): Texto cifrado a analizar.
- charset (string): Conjunto de caracteres utilizado en el cifrado.
 
RETORNO:
Objeto con la siguiente estructura:
{
    found: boolean,     // true si encontró un desplazamiento válido
    shift: number,      // Desplazamiento detectado
    matches: number,    // Número de palabras comunes encontradas
    text: string       // Texto descifrado con el mejor desplazamiento
}
 
FUNCIONAMIENTO:
1. Define lista de palabras comunes en español (45+ palabras)
   - Artículos: el, la, los, las, un, una, del, al
   - Preposiciones: de, en, para, con, por, sobre, sin, hasta, donde
   - Verbos: es, son, ser, hacer, puede, ha, fue
   - Pronombres: yo, tu, te, lo, se, su, nos, mi
   - Conjunciones: y, o, pero, cuando, si, porque
   - Adverbios: muy, tambien
   
2. Inicializa variables para almacenar el mejor resultado
   
3. Itera por todos los desplazamientos posibles (1 hasta longitud del charset)
   
4. Para cada desplazamiento:
   - Descifra el texto completo
   - Convierte a minúsculas para comparación
   - Cuenta cuántas palabras comunes contiene el texto descifrado
   - Si encuentra más coincidencias que el mejor resultado anterior, lo actualiza
   
5. Retorna el resultado con el desplazamiento que tuvo más coincidencias
   - Considera válido si encuentra al menos 2 palabras comunes
 
ALGORITMO MATEMÁTICO:
Para cada desplazamiento k de 1 a n:
    D(x) = (x - k) mod n    // Descifrar con desplazamiento k
    score(k) = Σ (palabra_común encontrada)
    
Seleccionar k_óptimo = argmax(score(k))
 
PSEUDOCÓDIGO:
INICIO autoDetectShift(input, charset)
    palabras_comunes = ['el ', 'la ', 'de ', 'que ', 'un ', 'es ', ...]
    
    mejor_resultado = {
        desplazamiento: 0,
        coincidencias: 0,
        texto: ''
    }
    
    longitud_charset = longitud de charset
    
    PARA desplazamiento de 1 hasta longitud_charset HACER
        resultado_descifrado = ""
        
        // Descifrar con este desplazamiento
        PARA cada caracter en input HACER
            posicion = buscar caracter en charset
            SI posicion encontrada ENTONCES
                nueva_posicion = (posicion - desplazamiento) mod longitud_charset
                SI nueva_posicion < 0 ENTONCES
                    nueva_posicion = nueva_posicion + longitud_charset
                FIN SI
                resultado_descifrado = resultado_descifrado + charset[nueva_posicion]
            SINO
                resultado_descifrado = resultado_descifrado + caracter
            FIN SI
        FIN PARA
        
        // Contar coincidencias con palabras comunes
        coincidencias = 0
        resultado_minusculas = convertir resultado_descifrado a minúsculas
        
        PARA cada palabra en palabras_comunes HACER
            SI resultado_minusculas contiene palabra ENTONCES
                coincidencias = coincidencias + 1
            FIN SI
        FIN PARA
        
        // Actualizar mejor resultado si es necesario
        SI coincidencias > mejor_resultado.coincidencias ENTONCES
            mejor_resultado.desplazamiento = desplazamiento
            mejor_resultado.coincidencias = coincidencias
            mejor_resultado.texto = resultado_descifrado
        FIN SI
    FIN PARA
    
    RETORNAR {
        encontrado: mejor_resultado.coincidencias >= 2,
        desplazamiento: mejor_resultado.desplazamiento,
        coincidencias: mejor_resultado.coincidencias,
        texto: mejor_resultado.texto
    }
FIN
 
EJEMPLO DE USO:
Input: "_|L45M(✔ (M (|Ƈ†O® Ƈ; ƇL(Ƈ Oƀ✔;® O®5eMƇ..."
Charset: "9loDZ7GdFajVAIitX1SyUHrEsPKhfucWqJvbwp2g..."
 
resultado = autoDetectShift(input, charset)
// resultado.found = true
// resultado.shift = 90
// resultado.matches = 4
// resultado.text = "Disfruta tu tiempo en este plano..."
 
VENTAJAS DEL ALGORITMO:
- No requiere conocimiento previo del desplazamiento
- Funciona con conjuntos de caracteres personalizados
- Robusto ante variaciones ortográficas
- Alta precisión con textos en español de más de 20 palabras
 
LIMITACIONES:
- Requiere que el texto descifrado esté en español
- Funciona mejor con textos largos (>50 caracteres)
- Puede ser lento con conjuntos de caracteres muy grandes (>500 caracteres)
- Mínimo 2 palabras comunes requeridas para validación

PROPÓSITO:
Procesa el texto aplicando el algoritmo de cifrado Atbash, que invierte

PARÁMETROS:
- Ninguno (obtiene datos directamente del DOM).

posicion_invertida = (longitud_conjunto - 1) - posicion_original

B (pos 1)  → Y (pos 24): 25 - 1 = 24
Z (pos 25) → A (pos 0):  25 - 25 = 0

    FIN SI
    
    // [FN-003.3] Inicialización
    resultado = ""
    longitud_conjunto = longitud de conjunto
    
    // [FN-003.4] Procesamiento

6. ALGORITMOS MATEMÁTICOS
 
6.1 Cifrado César - Fórmula General
 
Para un conjunto de caracteres de longitud n:
CIFRAR:   E(x) = (x + k) mod n
DESCIFRAR: D(x) = (x - k) mod n
 
Donde:
  x = posición del carácter en el conjunto (0 a n-1)
  k = clave de desplazamiento
  n = tamaño del conjunto de caracteres
  mod = operación módulo (resto de la división)
 
Ejemplo detallado:
Conjunto: "ABCDEFGHIJKLMNOPQRSTUVWXYZ"
n = 26
k = 3
 
Cifrar "HOLA":
  H → posición 7:  (7 + 3) mod 26 = 10 → K
  O → posición 14: (14 + 3) mod 26 = 17 → R
  L → posición 11: (11 + 3) mod 26 = 14 → O
  A → posición 0:  (0 + 3) mod 26 = 3 → D
 
Resultado: "KROD"
 
Implementación en el código (Línea 371):
let newIndex = (index + actualShift) % charsetLength;
 
Manejo de índices negativos al descifrar (Líneas 372-374):
if (newIndex < 0) {
    newIndex += charsetLength;
}
 
6.2 Detección Automática - Algoritmo de Frecuencia (NUEVO)
 
El algoritmo de detección automática se basa en el análisis de frecuencia de
palabras comunes, una técnica fundamental en criptoanálisis.
 
FÓRMULA:
Para cada desplazamiento k ∈ [1, n]:
    Score(k) = Σ (palabra_i ∈ D_k(C))
    
Donde:
  C = texto cifrado
  D_k = función de descifrado con desplazamiento k
  palabra_i = palabra común en español
  Score(k) = número de palabras comunes encontradas
 
Selección: k_óptimo = argmax(Score(k))
 
CRITERIO DE VALIDACIÓN:
Score(k_óptimo) ≥ 2    // Al menos 2 palabras comunes
 
COMPLEJIDAD COMPUTACIONAL:
Tiempo: O(n × m × p)
Donde:
  n = longitud del conjunto de caracteres (intentos de desplazamiento)
  m = longitud del texto cifrado
  p = número de palabras comunes a verificar (≈45)
 
Espacio: O(m)
 
EJEMPLO PRÁCTICO:
Texto cifrado: "KROD"
Conjunto: "ABCDEFGHIJKLMNOPQRSTUVWXYZ" (n=26)
 
Iteración k=1:  D_1("KROD") = "JQNC" → Score=0
Iteración k=2:  D_2("KROD") = "IPMB" → Score=0
Iteración k=3:  D_3("KROD") = "HOLA" → Score=1 (encontró "la")
...
Iteración k=23: D_23("KROD") = "NURO" → Score=0
 
Resultado: k_óptimo = 3, Score = 1
 
6.3 Cifrado Atbash - Fórmula General
 
E(x) = D(x) = (n - 1) - x
 
Donde:
  x = posición del carácter en el conjunto
  n = tamaño del conjunto
 
Ejemplo detallado:
Conjunto: "ABCDEFGHIJKLMNOPQRSTUVWXYZ"
n = 26
 
Cifrar "HOLA":
  H → posición 7:  (26-1) - 7 = 18 → S
  O → posición 14: (26-1) - 14 = 11 → L
  L → posición 11: (26-1) - 11 = 14 → O
  A → posición 0:  (26-1) - 0 = 25 → Z
 
Resultado: "SLOZ"
 
Implementación en el código (Línea 471):
const reversedIndex = charsetLength - 1 - index;

7. NOTAS TÉCNICAS ADICIONALES
 
Manejo de Caracteres Especiales
Los caracteres que no están en el conjunto definido permanecen sin cambios.
Esto permite cifrar texto con puntuación sin alterar los signos.
 
Implementación:
- César: Líneas 369-377
- Detección automática: Líneas 417-428
- Atbash: Líneas 470-474
 
Validaciones Implementadas
- Verificación de campos vacíos antes de procesar.
- Alertas informativas al usuario.
- Manejo de índices negativos en descifrado César.
- Validación de resultado en detección automática (mínimo 2 coincidencias).
 
Operación Módulo
La operación módulo previene desbordamiento del conjunto:
- Si el índice >= longitud: regresa al inicio.
- Si el índice < 0: ajusta sumando la longitud.
 
Optimizaciones de Detección Automática
- Búsqueda de palabras con espacios para evitar falsos positivos.
- Conversión a minúsculas para comparación insensible a mayúsculas.
- Lista extendida de 45+ palabras comunes para mayor precisión.
- Criterio de validación ajustable (actualmente 2 coincidencias mínimas).
